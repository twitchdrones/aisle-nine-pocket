# Aisle Nine Pocket

A phone web app that scans a barcode and works out Amazon FBA profit. Runs entirely in the browser and works offline after the first visit. No account, no server, no tracking.

Barcode reading by [zxing-wasm](https://github.com/Sec-ant/zxing-wasm) (MIT, see `vendor/LICENSE-zxing.txt`). Fees are estimates of Amazon's 2026 US rates. Not affiliated with Amazon.
